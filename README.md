# Post Studio · Sports Tech Nation

טופס להעלאת תמונה, שם וטייטל וליצירת פוסט PNG במידות **1080 × 1350**. הממשק נפתח באנגלית כברירת מחדל. בורר השפה בראש העמוד מאפשר לעבור לעברית, והבחירה נשמרת בדפדפן לביקור הבא. הטקסטים, הודעות העיבוד והשגיאות וכיוון הממשק מתעדכנים בלי לאבד את הפוסט שעורכים. שפת הממשק אינה משנה את שכבת העיצוב המקורית או את הפרטים שהוזנו.

במובייל, כשגוללים מהתמונה אל הבקרים, תצוגה מוקטנת מוצמדת לראש המסך ומתעדכנת בזמן העריכה. רוחבה חצי מרוחב התמונה הגדולה, עם הגבלת גובה למסכים קטנים ולמקלדת פתוחה. התמונה המקורית שומרת על מקומה כדי למנוע קפיצות בגלילה. בחזרה לאזור התמונה, או בלחיצה על ״Full preview״ / ״לתצוגה המלאה״, התצוגה המוקטנת נעלמת. היא אינה משנה את קובץ הפוסט שמורידים.

## הפעלה לפיתוח

דורש Node.js 22.12 ומעלה, או Node.js 24.

```sh
cd /workspace/codex-project
npm ci
npm run build
npm run dev -- --port 5173
```

התקנת התלויות מעתיקה את מודל הסרת הרקע ואת קובצי WebAssembly לתיקיית `public/vendor`. אין צורך במפתח API. השירות אינו מקבל את תמונות המשתמשים: עיבוד התמונות והפקת הפוסט מתבצעים בדפדפן, והתמונות אינן נשמרות בין ביקורים.

## שימוש

1. מלאו שם וטייטל והעלו תמונת PNG, JPG או WebP עד 20MB.
2. הסרת הרקע פועלת אוטומטית. אפשר לבטל אותה או להשתמש ב-PNG שכבר הוסר ממנו הרקע.
3. עיבוד עדין של בהירות, קונטרסט ורוויה פועל כברירת מחדל. אפשר לבטל אותו בתיבה ״עיבוד תמונה עדין״, או לכוון את הבקרים תחת ״תאורה, צבע וזוהר פנימי״.
4. כוונו גודל ומיקום תחת ״דיוק המיקום״. הזוהר הכתום מופיע בתוך שולי הדמות; אפשר לשנות את עוצמתו ורוחבו, או לקבוע עוצמה 0 כדי לבטל אותו. איפוס העיבוד ואיפוס המיקום פועלים בנפרד.
5. הורידו את הפוסט ב-PNG והעלו ללינקדאין.

לתוצאה הטובה ביותר: צילום אדם אחד, מול המצלמה, מהמותניים ומעלה, עם ידיים משולבות. עיבוד התמונה משנה צבע ובהירות בלבד, ושומר על הפנים, הפוזה והבגדים. הזוהר הפנימי משלב גוון כתום לאורך שולי הדמות ושומר על מסכת השקיפות שלה, ללא הילה מחוץ לדמות. העיבוד חל על תמונת האדם בלבד, לפני שכבת הטקסטים והלוגואים המקורית. איכות הסרת הרקע תלויה בתמונה; לדיוק בשיער ובפרטים קטנים עדיף PNG שהוכן מראש. דפדפן עם WebGL נדרש להסרה האוטומטית; תמונה שקופה קיימת עובדת גם בלי מודל ההסרה.

## שילוב שכבת הקאנבה המקורית

1. ייצאו מקאנבה **PNG עם רקע שקוף**, עם כל הטקסטים הקבועים והלוגואים, בלי האדם, השם והטייטל. ייצאו את כל הדף, בלי חיתוך.
2. פתחו בממשק ״הגדרת העיצוב ושיתוף הטופס״ והעלו את השכבה. היחס הצפוי הוא 4:5; מומלץ 1080 × 1350.
3. סדר השכבות: רקע שחור → תמונת האדם → שכבת הקאנבה → השם והטייטל המשתנים. השם והטייטל נמצאים באותם אזורים כמו בעיצוב שסופק.
4. לחצו ״הורדת האתר עם העיצוב שלי״. החבילה כוללת את השכבה המקורית בתוך `template.json`, וכל מבקר יראה אותה אוטומטית.

ברירת המחדל משתמשת ב-`public/template-overlay.png`, שכבת ה-PNG המקורית שהמשתמש סיפק ב-ZIP. הקובץ הועתק ללא שינוי, במידות 1080 × 1350, כולל כל הטקסטים הקבועים והלוגואים. הוא מופיע מעל תמונת האדם, והמערכת אינה מציירת לוגואים או טקסטים קבועים נוספים מתחתיו. תמונת האדם המוצגת לפני העלאה היא תמונת הדגמה שנערכה באמצעות AI מהצילום שסופק. אפשר להחליף שכבת עיצוב בממשק; שינוי מקומי אינו נשמר בשרת לאחר רענון. חזרה לעיצוב המקורי מחזירה את השכבה שפורסמה עם האתר.

כש״הסרת רקע אוטומטית״ מסומנת, המודל פועל גם על PNG עם שקיפות. שקיפות בפינות של תמונה עגולה אינה מעידה שהרקע שבתוך העיגול כבר הוסר. אם התמונה כבר מוכנה עם רקע שקוף נקי, אפשר לבטל את ההסרה כדי לשמר את המסכה המקורית.

## פרסום ושליחת קישור

נוסף מסלול פרסום אוטומטי ב-GitHub Pages דרך `.github/workflows/pages.yml`. הפעלה ראשונית דורשת לאפשר Pages במאגר ולבחור **GitHub Actions** כמקור הפרסום. לאחר מכן, עדכונים לענף `main` מפעילים התקנה מה-lockfile, בנייה, בדיקות דפדפן ופרסום. כשמשתמשים במאגר פרטי, נדרשת תוכנית GitHub שתומכת ב-Pages למאגרים פרטיים; אין צורך להפוך את קוד המקור לציבורי כדי לבנות את האתר, ואין לשנות את נראות המאגר אוטומטית.

בסביבת Codex נדרש לאפשר גישה ל-`api.github.com` כדי להפעיל ולבדוק Pages ול-`teller007.github.io` כדי לאמת את האתר הציבורי. שמירת דרישות רשת בטיוטת הסביבה אינה מפרסמת את האתר עצמו.

חלצו את חבילת האתר שהורדתם ופרסמו את תוכנה בשירות אחסון אתר סטטי התומך ב-HTTPS, למשל Netlify, Cloudflare Pages או GitHub Pages. אפשר לשלוח את הקישור לאחר הפרסום. האפליקציה משתמשת בנתיבים יחסיים ותומכת גם בפרסום תחת תיקיית משנה. אין צורך בשרת יישום, בסיס נתונים או חיבור לחשבון קאנבה. פתיחת `index.html` ישירות מקובץ מקומי אינה נתמכת; יש להגיש את הקבצים דרך HTTP או HTTPS.

תמונות המבקרים והשם והטייטל שלהם אינם נכללים בחבילת האתר. ההדגמה הקבועה כן נכללת. בעת שימוש בחבילת ההפצה, אין צורך ברשת חיצונית לצורך הסרת הרקע או טעינת פונטים: כל הקבצים נכללים באתר.

ליצירת חבילה עם עיצוב הדוגמה דרך שורת הפקודה:

```sh
npm run bundle
```

הקובץ נוצר ב-`artifacts/post-studio-site.zip`. לבדיקת גרסת ההפצה:

```sh
npm run preview -- --port 4173
```

## בדיקות

```sh
npm run build
npm test
```

בדיקות הדפדפן משתמשות ב-Chromium המותקן בסביבה ב-`/usr/bin/chromium`. בסביבה אחרת הגדירו `PLAYWRIGHT_CHROMIUM_EXECUTABLE` לנתיב הדפדפן. הבדיקות מכסות אנגלית כברירת מחדל, מעבר לעברית וחזרה בלי שינוי הפוסט, זכירת השפה, תרגום הודעות שגיאה, הסרת רקע בפועל, שימור מסכת השקיפות בזמן עיבוד צבע וזוהר פנימי, היעדר בקשות לשרתים חיצוניים, שימור שכבת הטקסטים והלוגואים, סדר השכבות, ייצוא PNG, עריכת שם בעברית, בקרי מיקום ועיבוד, הפצת תבנית בלי נתונים אישיים, טעינת האתר המיוצא בכתובת אחרת ותצוגת מובייל בשתי השפות.
